# R.E.P.O. 败者赛车 + 方块岛

给一起开私房的朋友装的两个 BepInEx 插件包。

- **败者赛车 1.4.0**：团灭后续跑、跑酷赛道、好友排行
- **方块岛 1.1.0**：我的世界主题 + 苦力怕/僵尸等生物

当前 Release zip 仍是上述版本。本机 Steam 已是败者赛车 **1.4.2** + 方块岛 **1.2.2**（过终点会停、最后一人颁冠）。重打包前不要把本 zip 当最新。

**进同一间房的人必须都装这两个**，否则跑酷对不齐，生物也挡不到你。

## 下载

打开本仓 [Releases](https://github.com/manyin6/LoserRacePack/releases/latest)，下载 `LoserRace-BlockIsland.zip`。

安装步骤见压缩包里的 `安装说明.txt`。
