# R.E.P.O. 败者赛车 + 方块岛

两个 BepInEx 插件的合包，方便一起开房安装。

- **败者赛车 1.4.2**：[ArenaKeepRacing](https://github.com/manyin6/ArenaKeepRacing) — 团灭后续跑、跑到终点颁冠、最后一人掉下去也颁冠
- **方块岛 1.3.1**：[BlockIslandRace](https://github.com/manyin6/BlockIslandRace) — 我的世界主题 + 苦力怕 / 僵尸等生物

**进同一间房的人必须都装这两个**，否则跑酷对不齐，生物也看不到。

## 下载

打开本仓 [Releases](https://github.com/manyin6/LoserRacePack/releases/latest)，下载 `LoserRace-BlockIsland.zip`。

安装步骤见压缩包里的 `安装说明.txt`。

源码与单独的 DLL 发布在上面两个仓库。本仓只提供合包，不包含插件源码。
